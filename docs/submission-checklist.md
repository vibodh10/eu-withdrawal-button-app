# Shopify submission checklist

## Core build
- Embedded admin UI with App Bridge
- Real OAuth flow
- Real Billing API or Managed Pricing flow
- Theme app extension reviewed on Dawn and at least one non-Dawn theme
- GDPR webhooks registered and documented
- Privacy policy URL
- Support URL
- Clear merchant onboarding steps
- No broken links, 404s, or dead settings
- App uninstall cleanup

## Functional QA
- Install on development store
- Add app block to storefront
- Submit withdrawal request as guest
- Send confirmation email
- Send merchant notification
- Review request in admin
- Export CSV
- Upgrade to Pro
- Downgrade to Basic
- Reinstall app and re-approve billing correctly if needed

## Listing setup
- Name
- Short description
- Detailed description
- App icon
- Demo video or screenshots
- Pricing section with Basic free and Pro £1/month
- Support contact
- Privacy policy
- Data handling disclosure
